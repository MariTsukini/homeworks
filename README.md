## Описание

Это Docker контейнер для выполнения R-скрипта (`analysis_script.R`). Скрипт анализирует данные из файла `Пациенты.xlsx` (который должен находиться в корне проекта) для определения уровня гемоглобина по возрастным группам. Результат анализа сохраняется в файл `hemoglobin_analysis.csv`.

-   `analysis_script.R`: R-скрипт, выполняющий анализ.
-   `Dockerfile`: Инструкции для Docker по сборке образа.
-   `Пациенты.xlsx`: Входной файл с данными.
-   `README.md`: Этот файл с инструкциями.
-   `results/`: Локальная директория для сохранения выходного файла `анализ_гемоглобина.csv`.

## Требования для Работы

-   **Docker Desktop** (с включенной интеграцией WSL2, если сидите в окне)
-   **Терминал WSL2**
-   Файлы `analysis_script.R`, `Dockerfile`, `Пациенты.xlsx` и `README.md` должны находиться в одной директории.

## Инструкция по Работе с Docker


1.  **Сборка Docker образа:**
    Эта команда создаст Docker образ под названием `hemoglobin_analysis`, основываясь на инструкциях в `Dockerfile`.
    ```bash
    docker build -t hemoglobin_analysis .
    ```

2.  **Запуск Docker контейнера:**
    Эта команда запускает контейнер из собранного образа. Флаг `-v` монтирует локальную папку `results` к `/home/results` внутри контейнера, обеспечивая сохранение `анализ_гемоглобина.csv`.
    ```bash
    docker run --rm -v "$PWD/results:/home/results" hemoglobin_analysis
    ```

    В результате в вашей папке `/results` будет создан файл `hemoglobin_analysis.csv`.
