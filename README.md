## Описание

1.  Генерирует синтетические данные (метаданные образцов, результаты масс-спектрометрии, данные о качестве) и сохраняет их в CSV-файлы в директории `input/`.
2.  Выполняет `INNER`, `LEFT`, `RIGHT` и `OUTER` объединения (join) этих данных.
3.  Логирует информацию о каждом шаге и результатах объединений в консоль.
4.  Сохраняет результаты каждого объединения в отдельные CSV-файлы в директории `output/`.
5.  Директория `output/` создается с правами `777`, чтобы быть доступной для записи из контейнера.

## Структура Проекта

*   `Dockerfile`: образ Docker для выполнения скриптов.
*   `requirements.txt`: список зависимостей.
*   `generate_data.py`: скрипт для генерации исходных данных.
*   `perform_joins.py`: скрипт для выполнения операций объединения и сохранения результатов.
*   `README.md`: Этот файл с инструкциями.

## Требования

Для запуска проекта вам потребуется установленный [Docker](https://www.docker.com/get-started).

## Инструкции по Запуску

Выполните следующие шаги в корневой директории проекта:

### 1. Создание исходных данных (вне Docker)

Сначала сгенерируйте входные данные, выполнив скрипт `generate_data.py`:

```bash
python generate_data.py
```
Собираем и запускаем контейнер
```bash
docker build -t pandas-joins .
docker run -v "$(pwd)/input:/app/input" -v "$(pwd)/output:/app/output" pandas-joins
```
В результате получаем 2 папки: input и output с результатами джоинтов
