Anti-Join с использованием dplyr

автоматическая обработка табличных данных в изолированной среде Docker. Скрипт на языке R генерирует тестовые наборы данных и выполняет anti-joins для поиска расхождений между таблицами.

## Функционал

1.  **Left Anti-Join:** Выделение записей, присутствующих только в первой таблице (Metadata), но отсутствующих во второй.
2.  **Right Anti-Join:** Поиск записей, которые есть только во второй таблице (Mass Spec), но не описаны в первой.
3.  **Outer Anti-Join:** Полный список уникальных записей, не имеющих пары в другой таблице.

## Структура проекта

-   `r-script.R` — основной скрипт: генерация данных, проверка библиотеки `dplyr` и выполнение join-операций.
-   `Dockerfile` — конфигурация для сборки образа на базе R.
-   `data/` — директория, куда сохраняются сгенерированные CSV-файлы и отчеты (создается автоматически).

## Предварительные требования

Для запуска необходимо наличие: \* Установленного **Docker Engine** \* Файлов `Dockerfile` и скрипта R в одной директории.

## Инструкция по запуску

### 1. Сборка образа

``` bash

docker build -t anti-join-dplyr .
```

### 1. Запускаем контейнер

``` bash
docker run -v "$(pwd):/app" anti-join-dplyr
```
